# How to do literature survey

## the best way of doing literature survey
1. Use an academic search engine with some well-chosen keywords to find 3-5 recent papers
2. Read first pass on each paper to get a sense of the work
3. Read related work sections to find a summary or survey of the recent work
4. Find shared citations and repeated author names in the bibliography to discover key papers(1) and researchers
5. Find key researchers recent published place to find top conferences
6. Scan top conference publications to identify recent high-quality related papers(2)
7. Read second pass through (1)(2) papers, if find shared citations add to key papers

## academic search engine
* dblp computer science bibliography
* google scholar
